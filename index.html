BasaltOS

A Linux distro on top of AlmaLinux. Easy enough for your first install, open enough to make it completely yours.

join the discord github

What we're building

Beginner-friendly

Install it and get going. Stuff should work out of the box without you digging through wikis first.

Stable base

Built on AlmaLinux, which is solid and supported for years, so we don't have to babysit the base and can spend our time on the stuff on top.

NVIDIA support

We want the NVIDIA drivers sorted for you during install, so your GPU just works on first boot.

Power-user ready

Good defaults, but nothing's locked down. Change whatever you want, it's your system.

Roadmap

  1. Foundations [in progress]

    Getting the base system going from AlmaLinux. Packaging, default config and NVIDIA support.

  2. First ISO [in progress]

    Alpha images for early testers. The first build is in internal testing right now, Join our Discord Server if you want to find out when the Alhpa ISO releaes

  3. Public release [planned]

    Stable releases you can grab from this page. No dates yet, and we'd rather not promise one we can't hit.
