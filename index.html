The pitch

Beginner-friendly

We will write why here once we have a reason to call it "beginner friendly". But AlmaLinux isn't that complicated to begin with

Stable base

Built on AlmaLinux, because maintaining our own kernel is how projects become cautionary tales. Boring where it counts, which is exactly what a base should be.

NVIDIA support

Packages and configurations for NVIDIA GPUs, sorted at first boot instead of after a forum thread.

Power-user ready

Sane defaults out of the box. Tear them apart. We'd do the same.

The plan

  1. Foundations [planned]

    Base system on AlmaLinux: packaging, configurations, NVIDIA support. Starting slowly... That's the honest status.

  2. First ISO [planned]

    Bootable test images, eventually. The Discord hears first, even if the announcement is a bit sheepish.

  3. Public release [planned]

    Stable releases, and this page grows a download button. No dates (dates are how we got into this situation)
